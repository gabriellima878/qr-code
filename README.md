# Frontend Mentor - QR Code Component Solution

This is my solution to the **QR Code Component** challenge on [Frontend Mentor](https://www.frontendmentor.io/challenges/qr-code-component-iux_sIO_H).

![Design preview](./preview.jpg)

## ✨ Overview

This challenge was about creating a centered, responsive card component that visually matches the provided Figma design. It features a QR code image and two blocks of text, styled with precision and consistency.

### 🔗 Live Site

[👉 View Live Project Here](https://gabriellima878.github.io/qr-code/)

---

## 📚 Technologies Used

- HTML5  
- CSS3  
- Flexbox  
- Mobile-first workflow  
- Figma (Dev Mode for exact spacing and sizing)

---

## ✅ Features

- Pixel-perfect implementation of the design  
- Fully responsive layout (mobile and desktop)  
- Semantic HTML structure  
- Clean, maintainable CSS using custom properties  
- Accessible alt text and consistent visual spacing

---

## 📐 Layout Details

- Component width: `320px`  
- Border-radius: `20px` for the card, `10px` for the image  
- Padding: `16px` on top and sides, `40px` on bottom  
- Typography: [Outfit](https://fonts.google.com/specimen/Outfit), weights 400 and 700  
- Centered layout using Flexbox (`min-height: 100vh`)

---

## 🚀 What I Learned

- How to create visually balanced components using spacing tokens  
- How to center elements vertically and horizontally with Flexbox  
- How to apply consistent border-radius and padding across elements  
- How to use Figma Dev Mode to extract style values precisely
